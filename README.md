# My Second Place AI — コンセプト・プロトタイプ

人生後半の毎日を支える、パーソナルAI秘書の試作版です。
「AI秘書（予定・やること）」「自分専用の大学」「長期記憶」の3つがつながると何ができるかを、スマホで触って確かめられます。

**▶ 試作版を開く：https://akiraspecial.github.io/my-second-place-ai/**
（スマホでの表示を想定しています。パソコンでも開けます）

## 3分の見どころ

1. 「今日」の画面で **「相談する」** を押す
2. AIが「来週の予定に、運動と大学の勉強を組み込んで」に答えて、計画を提案します。
   通院と会食を避け、「覚えていること」（歩くのは30分が続けやすい／学ぶのは午後が集中できる）をもとにしています
3. **「この予定で登録する」** を押すと、はじめて予定に入ります（押すまでは何も変わりません）
4. 「予定」を開くと、AIが追加した予定に **「AIが追加」** の印が付いています
5. 「覚えていること」では、AIが何を覚えているかを見て、直したり忘れてもらったりできます。新しく覚えるときは本人に確かめます
6. 「機能をふやす」では、健康・音声日記・推し活などを、必要な人が必要な分だけ足せます（育つアプリ）

## 設計の考え方

- **「今日」が中心**：開いたら、今日の予定とやることがすぐ分かる。ボタンは大きく、数を絞る
- **承認してから実行**：予定ややることを変えるのは、本人が「はい」と言ったときだけ
- **記憶が見える**：AIが覚えていることを本人が見られ、直せて、消せる
- **育つアプリ**：みんなに同じ機能を配るのではなく、共通のAIと記憶に、本人が必要な機能を足していく
- 本番では、オープンソースのAIエージェント基盤 MulmoClaude を土台にする計画です

## この試作版でしていないこと

- 本物のAIへの接続はしていません。AIの返事は、決めておいた台本で返します（話しかける例のボタンから試せます）
- Googleカレンダーなどとの連携、ログイン、声での入力はしていません
- データはお使いのブラウザの中だけに保存されます。「試作版を最初からやり直す」で初期状態に戻ります
- 「機能をふやす」で追加した機能の中身は、これからの開発で作ります

## つくり

HTML・CSS・JavaScript だけの静的サイトです（ビルド不要）。

```bash
npm install
npx playwright install chromium
npm run verify   # スマホ幅で全画面と主な流れを自動検査し、shots/ に画面写真を出します
```
