# My Second Place AI — Personal Life OS（プロトタイプ v0.2）

**自分の人生を覚え、暮らしを支え、世界とつながるパーソナルAI**

健康・学び・日記・写真・関心情報・投資・人生の記録は、ふつうは別々のアプリに散らばっています。この試作版では、それらを1か所に記録し、**ひとつのAIが記録をまたいで理解し、予定や行動に落とし込む**体験を、スマホで確かめられます。

**▶ 試作版を開く：https://akiraspecial.github.io/my-second-place-ai/**
（スマホでの表示を想定しています。パソコンでも開けます）

## 3分の見どころ

1. **ホーム「今日」**：今日の予定とタスクの件数、6つのボタン（予定・やること・健康・大学・日記・すべて）、「AIに話しかける」
2. **AI秘書**：「相談する」を押すと、AIが来週の運動と大学の勉強の計画を提案します。通院と会食を避け、「覚えていること」を理由に示します。**「この予定で登録する」を押すまで、予定は変わりません**
3. **記録をまたぐ提案**：「AIに話しかける」で「最近運動不足だから、何か始めたい」を押すと、**健康の記録（歩数の平均）・関心情報（地域のウォーキング会）・大学（運動の講義）**をまたいで提案します
4. **My Personal University**：学部 → 科目 → 講義。AI講義ノート、ことばの説明、小テスト、AI教授への質問。「地元の歴史を学ぶ学部をつくって」と頼むと、12週の計画をつくり、承認すると学部ができます
5. **すべて**：Personal Life OS の全体図（画面 → AIエージェント → 機能 → Personal Data & Memory → 外の情報）。ここで機能を足したり外したりできます（育つアプリ）

## 画面と、できること

| 画面 | できること |
|---|---|
| 今日 | 今日の予定・タスク・学びの進み具合、6つの入口 |
| AIと話す | 予定の提案と登録、昨日の残りを明日へ、記録をまたぐ提案、学部づくり、日記のふりかえり、ことばの説明 |
| すべて | Personal Life OS の全体図、機能を足す・外す |
| 予定・やること | 追加・完了・削除。AIが追加したものには印 |
| 健康 | 歩数・体重・睡眠・食事・運動の記録、7日のグラフ |
| 大学 | 4学部（健康長寿・AI・資産形成・人生後半デザイン）、講義ノート、小テスト、教材の登録 |
| 日記 | 書く・声で入力（対応ブラウザ）・言葉で探す |
| 写真 | 写真とメモを保存 |
| 関心情報 | コミュニティ・推し活・YouTube・Podcast の情報源を登録、新着の例 |
| 投資 | テーマのウォッチリスト（判断はかわりにしない） |
| 人生の記録 | 価値観・経験・目標 |
| 覚えていること | AIの長期記憶を見る・直す・忘れてもらう。新しく覚えるときは本人に確かめる |
| データ管理 | 記録をJSONで書き出す・読み込む・最初の状態にもどす |

## 設計の考え方

- **ひとつのAIが、領域をまたいで理解する**：9つのアプリを作るのではなく、共通の記録と記憶の上に機能を並べる
- **承認してから実行**：予定・やること・学部・記憶を変えるのは、本人が「はい」と言ったときだけ
- **記録とAIの記憶を分ける**：「1日6,200歩」は記録として正確に残し、「最近よく歩いている」はAIの記憶として持つ
- **育つアプリ**：みんなに同じ機能を配るのではなく、本人に必要な機能を足していく
- **健康と投資は判断を代行しない**：理解と意思決定を支える
- 本番では、オープンソースのAIエージェント基盤 **MulmoClaude**（Personal Wiki・Collections・Feeds・Skills・Scheduler・Remote Access）を土台にする計画です

## この試作版でしていないこと

- 本物のAIへの接続はしていません。AIの返事は、決めておいた台本で返します（「話しかける例」から試せます）
- MulmoClaude との接続、外部情報の自動収集、Googleカレンダーとの同期、ログインはしていません
- 記録はお使いのブラウザの中だけに保存されます
- 登場する予定・記録・記憶は、説明のための例です

```bash
npx playwright install chromium
npm run verify   # スマホ幅で全16画面と13の流れを自動検査し、shots/ に画面写真を出します
```
